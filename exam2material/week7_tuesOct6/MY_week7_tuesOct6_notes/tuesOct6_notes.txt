Domain: ℤ (the integers) - positive and negative and zero


What do these mean in English? Are they true?


∀ n ∃ m (n^2 < m)

    For all numbers, its square is less than some other number.
    TRANSLATION: The square of every integer is less than some other integer.

    TRUE: The set of integers is infinite (you can just add 1)


∀ x ∃ y (x == y^2)

    For all integers, it is some perfect square.
    FALSE: 5 is not a perfect square


∀ n ∃ m (n^2 == m)

    For all squared integers, they are some resulting integer.
    TRUE: When you square an integer, it will always result an integer.

    (integers are closed under multiplication)


∃ m ∀ n (n^2 == m)

    Translation: There is one number that is the square of all other numbers
    FALSE: That doesn't work!

Arguments in predicate logic

Set of premises
Conclusion

Argument is VALID: regardless of domain,
    whenever all the premises are true,
    then the conclusion is also true

Argument is INVALID: we can find a domain where
    all the premises are true but the conclusion is false



Examples -- are the following arguments valid?
